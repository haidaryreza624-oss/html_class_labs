# HTML Class Lab

## Overview

This repository contains my HTML class lab work. It includes exercises, practice files, and mini-projects that demonstrate my understanding of core HTML concepts.

## Objectives

* Learn the structure of an HTML document
* Understand and use common HTML tags
* Practice building simple web pages
* Apply semantic HTML principles

## Lab Contents

The lab includes:

* Basic HTML page structure
* Headings, paragraphs, and text formatting
* Links and images
* Lists (ordered and unordered)
* Tables
* Forms and input elements

## Technologies Used

* HTML5



## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/html-class-lab.git
   ```
2. Open the folder
